
# Children's Book Translation Lab

## Translating. Learning. Contributing.

Welcome to my children's book translation project.

I'm using short, Level 1 children's books as a practical way to develop my Spanish and Swahili language skills while contributing translations where permitted.

Rather than following a traditional language-learning curriculum, I'm building fluency through repeated exposure, translation, revision, and reflection.

### The Approach

Each book becomes a small translation project:

**Read → Translate → Review → Revise → Submit → Learn**

I'm also documenting how my use of AI changes over time.

At the beginning, I'll rely heavily on AI for translation assistance, explanations, corrections, and language learning. As my fluency develops, the goal is to move toward increasingly independent translation and use AI primarily as a reviewer and tutor.

### Languages

🇪🇸 Spanish
🇰🇪 Swahili
🇺🇸 English

The language direction may vary from book to book. I'm intentionally keeping the project flexible so that I can work with whichever Level 1 books are available and appropriate.
